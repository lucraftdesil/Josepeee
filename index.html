Este patrón, si se usa para presionar a usuarios reales, es sancionable bajo GDPR (UE), CCPA (California) y guías de la FTC. Úsalo solo para entender la mecánica.

Notificaciones push reales (20)

Esta página usa la Notification API nativa del navegador. Por diseño de seguridad de los navegadores, el permiso solo se puede pedir una vez — no es posible que una web muestre 20 prompts de permiso seguidos. Si aceptas una vez, se disparan 20 notificaciones reales del sistema operativo.

Paso 1 — Permiso del navegador

Comprobando soporte…

Al hacer clic se abre el prompt nativo del navegador (no se puede personalizar ni repetir). Si lo bloqueas o cierras, tendrás que cambiarlo manualmente en la configuración del sitio para volver a intentarlo.

Paso 2 — Disparar las 20 notificaciones reales

Se enviarán con un pequeño intervalo entre cada una (los navegadores pueden agrupar o limitar notificaciones muy seguidas; eso también es comportamiento real, no simulado).
